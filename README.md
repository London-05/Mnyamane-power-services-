# Mnyamane Power Services Website

A responsive website for Mnyamane Power Services, an electrical and solar company based in Johannesburg, South Africa.

## About
Mnyamane Power Services provides professional electrical services, Certificate of Compliance, wiring, maintenance, and solar system installations.

## Website Pages
- **Home**: Company introduction and services overview
- **About Us**: Company history, mission and vision
- **Services**: Electrical, COC, Wiring & Maintenance
- **Solar Solutions**: 5KW, 8KW, 12KW Solar Systems
- **Gallery**: Photos of past installations
- **Contact Us**: Quote form, location, WhatsApp, Facebook

## Technologies Used
- HTML5
- CSS3
- JavaScript
